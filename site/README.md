# Site — sereinapp.fr/relais

Page de présentation de Serein Relais, à déposer dans `/home/pi/sereinapp-landing/relais/` sur le serveur (le reste de sereinapp.fr n'est pas dans ce repo).

- `relais/` est un petit site autonome (novembre 2026) : `index.html` (accueil), `exercices/` (les sept exercices), `psys/` (pour les psys), `pourquoi.html`, `privacy.html`. Le CSS et le JS sont **recopiés tels quels** de la landing Serein (`index.html` pour l'accueil, `pro/index.html` pour les pages intérieures, `pourquoi-serein.html` pour `pourquoi.html`), puis complétés par un bloc « Spécifique Serein Relais ». Polices et badges sont dans `relais/assets/` (copies de ceux du serveur), donc le site fonctionne seul. **Ne pas publier avant la sortie de l'app** ; à la sortie, remplacer les badges « Bientôt » par les liens des stores (accueil, `psys/`, `pourquoi.html`).
- Logo : « le R en deux gestes » (choisi le 12/11/2026, kit complet et règles d'usage dans `icones/kit-b/`, pistes écartées dans `icones/pistes-3/` et `kit-c/`). Sur le site : `img/logo-relais.svg` (icône arrondie), `img/favicon-relais.svg` + `.ico` (coupe petites tailles), `img/apple-touch-icon-relais.png`. Pour l'app, `tools/icons/logo-relais.svg` → `node tools/icons/make-sources.mjs` → `npx capacitor-assets generate`.
- `relais/privacy.html` : copie de `privacy.html` (racine du repo) avec un lien retour et une icône adaptés au site. À régénérer après toute modification de `privacy.html`. Seule page publiée avant la sortie (URL exigée par les stores).
- `relais/img/` : captures de l'app (720 px de large), prises avec des données d'exemple.
- `relais/img/og-relais.png` : image de partage (1200 × 630), générée depuis `outils/og-relais.html` (à copier dans `relais/og.html` pour que les chemins des polices et du logo tombent juste, puis capture 600 × 315 à l'échelle 2, par exemple avec `outils/og-render.cjs`, Playwright).
- `landing-liens-relais.patch` : liens vers Relais à ajouter sur la landing Serein (pied de page et bloc « pro » de l'accueil, section dédiée sur `pro/`). **À appliquer seulement à la sortie**, sur une copie fraîche du serveur : `patch -p1 -d /home/pi/sereinapp-landing < landing-liens-relais.patch` (après une sauvegarde dans `.backups/`, comme d'habitude).
- `stores/` : captures pour l'App Store et Google Play.
